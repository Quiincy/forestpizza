# 🌲 Forest Pizza To Go — Офіційний сайт та система замовлень

Сучасний, швидкий та адаптивний веб-сайт піцерії **Forest Pizza** у Києві (Лісовий проспект, 11).

Формат роботи закладу: **Самовивіз (Takeaway) та доставка** (70 ₴ по Лісовому масиву, на таксі за межі).

Побудовано на стеку:
- **Next.js 16** (App Router, Turbopack, React 19)
- **Tailwind CSS v4** (Фірмова помаранчево-графітова палітра Forest Pizza)
- **PostgreSQL** (Prisma ORM)
- **Telegram Bot API** (Миттєве надсилання замовлень піцайоло на кухню)
- **Admin Dashboard** (`/admin`) (Повний контроль над замовленнями, меню, цінами та налаштуваннями)

## 🛵 Доставка та Самовивіз

- **Кур'єром по Лісовому масиву**: фіксовано **70 грн** (30–45 хв).
- **На таксі**: за межі Лісового масиву за тарифом таксі.
- **Самовивіз**: без черги за 15–20 хвилин (Київ, Проспект Лісовий, 11).
