# 🌲 Forest Pizza — Офіційний сайт та панель керування

Сучасний, швидкий та адаптивний веб-сайт піцерії **Forest Pizza** у Києві (Лісовий проспект, 11).

Формат роботи закладу: **Тільки на винос (Takeaway / Самовивіз) та доставка**. Столів для посадки немає.

Побудовано на стеку:
- **Next.js 16** (App Router, Turbopack, React 19)
- **Tailwind CSS v4** (Темна смарагдова лісова палітра з теплими золотими акцентами)
- **PostgreSQL** (Prisma ORM)
- **Telegram Bot API** (Миттєве надсилання замовлень на винос піцайоло на кухню)
- **Admin Dashboard** (`/admin`) (Повний контроль над замовленнями на винос, онлайн-кошиком, меню та налаштуваннями)

## 🏃 Замовлення на винос (Takeaway)

- Клієнти обирають:
  1. **Час готовності**: «🔥 Якомога швидше (15-20 хвилин)» або точний час (наприклад, 18:30, 19:00).
  2. Ім'я та телефон для видачі.
  3. Побажання до піци (порізати на 8 шматочків, додати соус, забрати з авто тощо).
- Замовлення зберігається в PostgreSQL та **миттєво летить у Telegram** боту / в робочий чат персоналу.
- Точка видачі: **м. Київ, Лісовий проспект, 11**.

## 🔐 Панель адміністратора (`/admin`)

Посилання: [http://localhost:3000/admin](http://localhost:3000/admin)

- **Пароль за замовчуванням**: `forest2026`
*(Пароль можна змінити в будь-який момент у вкладці «Налаштування»)*

### Можливості адмінки:
1. **Огляд (Dashboard)**: лічильники замовлень на винос за сьогодні, статус підключення Telegram-бота.
2. **Замовлення на винос**: список попередніх замовлень на час, швидкий дзвінок клієнту, зміна статусів («В роботу», «Видано клієнту»), експорт у CSV.
3. **Онлайн-кошик**: замовлення з точним складом піц, бортиків та соусів.
4. **Меню**: додавання страв, зміна цін на 30 та 40 см, редагування інгредієнтів, увімкнення/вимкнення наявності.
5. **Налаштування**:
   - Токен та Chat ID Telegram-бота з кнопкою тесту **«🚀 Надіслати тестове повідомлення»**
   - Точка видачі (Лісовий просп., 11), телефон, середній час приготування (15-20 хв), години роботи
   - Зміна пароля входу
